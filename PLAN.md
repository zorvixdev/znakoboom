# Знакобум — план проекта

## Идея

Telegram Mini App, в которой игрок тратит игровую валюту на генерацию
автомобильных номеров, собирает редкие комбинации и постепенно развивает свою
коллекцию, выбирает персональную специализацию и собирает номера регионов.
Это развлекательная игра: внутриигровая валюта не имеет денежной стоимости и
не выводится из игры.

## Структура

- `web/` — адаптивный интерфейс Telegram Mini App: генератор, коллекция,
  улучшения, награды, задания, регионы, рейтинг и статистика.
- `server.py` — HTTP-сервер, Telegram Web App initData-аутентификация,
  игровой API и хранение состояния в SQLite.
- `bot.py` — Telegram-бот на стандартной библиотеке Python: `/start`, кнопка
  запуска Mini App и long polling.
- `data/` — SQLite-база, создаётся автоматически и не попадает в git.
- `.env.example` — пример настроек; токен бота хранится только в окружении.

## Этапы

### MVP — реализовано

1. Собрать тёмный мобильный интерфейс по референсам с игровым домашним экраном
   и навигацией между разделами.
2. Реализовать генератор с выбором страны, случайным номером, редкостью,
   стоимостью, списанием баланса, наградой опыта и ростом уровня.
3. Добавить сохранение баланса, прогресса, настроек, коллекции, сейфа и витрины
   в SQLite; предоставить локальный демо-режим без Telegram для разработки.
4. Реализовать выбор любого региона, переплавку номеров и хэллоуинское
   событие с тыквами и эксклюзивной рамкой.
5. Реализовать улучшения генератора, хранилища, сейфа и витрины, а также
   ежедневную награду и статистику.
6. Добавить персональные специализации: «Нумеролог», «Автодилер», «Механик»
   и «Архивариус», каждая с постоянным уникальным бонусом.
7. Добавить дополнительные регионы России: Башкортостан и Краснодарский край.
8. Подключить Telegram-бота с кнопкой открытия Mini App и валидировать
   Telegram initData на сервере.
9. Описать локальный запуск и публикацию за HTTPS reverse proxy.
10. Добавить ежедневные заказы, каталог регионов с прогрессом, рейтинг игроков
    и реферальную программу с однократными наградами.

### Следующие этапы

1. Достижения за долгосрочный игровой прогресс и новые сезоны с наградами.
2. Коллекционные серии и особые заказы на комбинации номеров.
3. Турниры и дополнительные рейтинги после накопления достаточного числа игроков.
4. Дополнительный мониторинг антифрода и баланса, если появятся соревнования
   между игроками.

## Принципы MVP

- Генерация и награды рассчитываются сервером, а не доверяются браузеру.
- В режиме разработки данные сохраняются отдельно для локального игрока;
  production-режим требует Telegram initData и токен бота.
- Никаких платежей, вывода денег, ставок или обмена игровой валюты на деньги.
- Python API использует стандартную библиотеку; фронтенд запускается без сборки.
