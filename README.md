# Знакобум — пошаговая инструкция

**Знакобум** — Telegram-игра: нажимай на генератор, получай автомобильные
номера разных регионов, собирай редкости, улучшай коллекцию и выбери личный
бонус. Игровые рубли придуманы только для игры: их нельзя купить, вывести или
обменять на настоящие деньги.

Проект находится в отдельной папке `znakoboom`. Никакие файлы из
`site/` для его запуска не нужны.

## Что уже есть в игре

- Номера России, Казахстана и Беларуси; в России доступны, в частности,
  Башкортостан (102) и Краснодарский край (23).
- Шесть уровней редкости: легендарный — самый ценный и редкий.
- Сохранение баланса, опыта, уровней, ежедневных наград, коллекции, сейфа
  и витрины на сервере.
- Улучшения генератора и хранилища.
- Личный постоянный бонус на выбор: «Нумеролог», «Автодилер», «Механик»
  или «Архивариус».
- Нажатие прямо на номер запускает генератор; можно выбрать страну и любой
  конкретный регион, либо оставить «Любой регион».
- Переплавка: пять номеров одной редкости превращаются в один следующей
  редкости за игровую валюту.
- Ежедневные задания с серверным прогрессом и наградами.
- Атлас всех доступных регионов и выбор региона прямо из атласа.
- Таблица лидеров по накопленному опыту.
- Реферальные ссылки: пригласивший и новый игрок получают по 50 000 игровых
  рублей после первого открытия Mini App приглашённым игроком.
- Хэллоуин-событие 1 октября — 13 ноября 2026 года: шанс найти тыкву
  в генераторе, награды за ежедневный вход и активную игру, эксклюзивная рамка
  за 100 тыкв.
- Адаптивный интерфейс в стиле референсов.

## Что понадобится

Чтобы **посмотреть игру на своём компьютере**:

- Python версии 3.8 или новее. Установка дополнительных пакетов не нужна.

Чтобы **дать открыть игру другим людям в Telegram**:

- аккаунт Telegram;
- бот, созданный через `@BotFather`;
- сервер, постоянно подключённый к интернету (например, VPS с Ubuntu);
- доменное имя, которое можно направить на IP-адрес сервера.

Публичная версия мини-приложения обязательно открывается по HTTPS. Обычный
адрес `http://127.0.0.1:8080` работает только на том же компьютере и Telegram
не может использовать его как публичную игру.

## Шаг 1. Запусти игру у себя

### Windows

1. Установи Python с [python.org](https://www.python.org/downloads/). Во время
   установки отметь **Add Python to PATH**.
2. Открой папку `znakoboom` в Проводнике.
3. В адресной строке папки набери `cmd` и нажми Enter.
4. В чёрном окне введи:

   ```bat
   py server.py
   ```

### macOS или Linux

Открой терминал и выполни:

```sh
cd /путь/до/znakoboom
python3 server.py
```

Не закрывай окно терминала: в нём работает игровой сервер. Открой браузер на
этом же компьютере и перейди на http://127.0.0.1:8080. Это локальная демо-
версия с тестовым игроком `Гость`; прогресс сохраняется в файле базы данных.

Проверить работу можно без браузера, открыв http://127.0.0.1:8080/api/health:
должен появиться ответ `{"ok": true, "mode": "development"}`. Чтобы остановить
сервер, нажми Ctrl+C в окне терминала.

## Шаг 2. Создай своего Telegram-бота

1. Открой в Telegram [@BotFather](https://t.me/BotFather) и нажми **Start**.
2. Отправь команду `/newbot`.
3. Придумай отображаемое имя, например **Знакобум**.
4. Придумай свободное имя пользователя бота, которое заканчивается на `bot`,
   например `znakoboom_game_bot`. Если имя занято, попробуй другое.
5. BotFather пришлёт длинный **HTTP API token** — строку из цифр, двоеточия
   и букв.
6. Сохрани токен в надёжное место. Это пароль от бота:
   - никому его не пересылай;
   - не публикуй в чате, скриншоте, GitHub или файле `web/`;
   - если случайно раскрыл — в BotFather отзови его через `/revoke` и обнови
     `BOT_TOKEN` на сервере.
7. Сохрани точное имя пользователя бота без `@`, например
   `znakoboom_game_bot`: оно потребуется для создания персональных ссылок
   приглашения.

Пользователи открывают игру **через бота**, а бот передаёт приложению
подтверждённые Telegram-данные. Не отправляй токен BotFather в код сайта.

## Шаг 3. Подготовь адрес для Telegram

Публичной игре нужно доменное имя, например `game.example.ru`, и HTTPS.
Владелец домена должен направить DNS-запись `A` на IP-адрес твоего сервера.
Если ты не настраивал IPv6, не добавляй запись `AAAA`.

Ниже — один конкретный способ для VPS с **Ubuntu**. Если домен или VPS уже
есть, просто используй свои адрес и IP. В панели управления доменом обычно
нужно создать такую запись:

| Тип | Имя | Значение |
| --- | --- | --- |
| `A` | `game` или `@` | публичный IPv4-адрес VPS |

После изменения DNS иногда требуется подождать несколько минут или дольше.
Провайдер VPS должен разрешать входящие подключения к портам **80 и 443**.
Порт `22` нужен для подключения к серверу по SSH. Игровой порт `8080`
публиковать в интернете не надо — HTTPS-прокси передаст запросы локально.

### Как подключиться к VPS и перенести папку

1. В личном кабинете VPS найди публичный IPv4 сервера и имя пользователя
   Ubuntu. Обычно это `ubuntu` или пользователь, которого ты создал.
2. На Windows открой PowerShell или Windows Terminal; на macOS/Linux открой
   «Терминал». Подключись к VPS:

   ```sh
   ssh ИМЯ_ПОЛЬЗОВАТЕЛЯ@IP_АДРЕС_СЕРВЕРА
   ```

   Например: `ssh ubuntu@203.0.113.10`. Первый раз подтверди подключение,
   введя `yes`, а затем введи SSH-пароль или используй SSH-ключ. Это **пароль
   от VPS**, не токен Telegram-бота.
3. Скопируй папку `znakoboom` с компьютера на VPS. В macOS/Linux можно открыть
   второе окно терминала на своём компьютере и выполнить:

   ```sh
   scp -r /путь/к/папке/znakoboom ИМЯ_ПОЛЬЗОВАТЕЛЯ@IP_АДРЕС_СЕРВЕРА:/home/ИМЯ_ПОЛЬЗОВАТЕЛЯ/znakoboom
   ```

   Замени оба примера имени пользователя, IP и путь на свои. На Windows
   новичку проще установить [WinSCP](https://winscp.net/), войти в него по
   SFTP тем же пользователем и SSH-паролем/ключом, а затем перетащить папку
   `znakoboom` в `/home/ИМЯ_ПОЛЬЗОВАТЕЛЯ/`.
4. Вернись в первое SSH-окно. В командах следующего шага укажи реальный путь
   к загруженной папке, например
   `/home/ubuntu/znakoboom/server.py`.

## Шаг 4. Поставь приложение на VPS

Открой терминал/SSH-подключение к Ubuntu и обнови систему:

```sh
sudo apt update
sudo apt install -y python3 caddy
```

Создай отдельного системного пользователя и папку для игры:

```sh
sudo useradd --system --home /opt/znakoboom --create-home --shell /usr/sbin/nologin znakoboom
sudo mkdir -p /opt/znakoboom/web /opt/znakoboom/data
sudo cp /путь/до/znakoboom/server.py /opt/znakoboom/server.py
sudo cp /путь/до/znakoboom/bot.py /opt/znakoboom/bot.py
sudo cp -r /путь/до/znakoboom/web/. /opt/znakoboom/web/
sudo chown -R znakoboom:znakoboom /opt/znakoboom
```

Замени `/путь/до/znakoboom` на реальное расположение проекта. Например, если
папка проекта находится в `/root/znakoboom`, используй этот путь.

Создай файл настроек:

```sh
sudo nano /opt/znakoboom/.env
```

Вставь в него, заменив адрес и токен своими данными:

```dotenv
BOT_TOKEN=ВСТАВЬ_СЮДА_ТОКЕН_BOTFATHER
BOT_USERNAME=имя_бота_без_собаки
APP_URL=https://game.example.ru
APP_ENV=production
HOST=127.0.0.1
PORT=8080
DATABASE_PATH=data/znakoboom.sqlite3
```

Для сохранения в редакторе `nano` нажми **Ctrl+O**, Enter, затем **Ctrl+X**.
Закрой доступ к секрету и выдай папку игровому пользователю:

```sh
sudo chown znakoboom:znakoboom /opt/znakoboom/.env
sudo chmod 600 /opt/znakoboom/.env
sudo chown -R znakoboom:znakoboom /opt/znakoboom
```

`APP_URL` должен точно совпадать с публичным HTTPS-адресом приложения. Не
вставляй в него путь вроде `/index.html`; здесь достаточно домена.

## Шаг 5. Включи автозапуск игрового сервера

Создай системную службу:

```sh
sudo nano /etc/systemd/system/znakoboom.service
```

Вставь:

```ini
[Unit]
Description=Znakoboom Telegram Mini App
After=network.target

[Service]
Type=simple
User=znakoboom
Group=znakoboom
WorkingDirectory=/opt/znakoboom
ExecStart=/usr/bin/python3 /opt/znakoboom/server.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Сохрани файл (`Ctrl+O`, Enter, `Ctrl+X`) и запусти службу:

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now znakoboom
sudo systemctl status znakoboom
```

Если видишь `active (running)`, сервер запустился. Нажми `q`, чтобы выйти из
просмотра статуса. Смотреть сообщения сервера можно так:

```sh
sudo journalctl -u znakoboom -n 50 --no-pager
```

## Шаг 6. Включи HTTPS

Убедись, что DNS уже указывает на VPS. Открой конфигурацию Caddy:

```sh
sudo nano /etc/caddy/Caddyfile
```

Замени содержимое этим текстом, указав вместо `game.example.ru` свой домен:

```caddy
game.example.ru {
    reverse_proxy 127.0.0.1:8080
}
```

Сохрани и перезапусти Caddy:

```sh
sudo systemctl reload caddy
sudo systemctl status caddy
```

Caddy сам получает и продлевает HTTPS-сертификат. Подожди, пока DNS обновится,
затем открой `https://game.example.ru` в браузере. Должна появиться игра
**Знакобум** без предупреждений безопасности. Если сайт не открывается,
проверь DNS, порты 80/443 и сообщения `sudo journalctl -u caddy -n 50 --no-pager`.

## Шаг 7. Привяжи домен к боту

1. Открой `@BotFather`.
2. Отправь `/setdomain`.
3. Выбери своего бота.
4. Отправь только доменное имя, например `game.example.ru` — **без**
   `https://` и без `/`.
5. Перезапусти игровой сервер, чтобы он подхватил настройки:

   ```sh
   sudo systemctl restart znakoboom
   ```

## Шаг 8. Запусти Telegram-бота

Сервер игры и бот — два отдельных процесса. Для бота создай вторую службу:

```sh
sudo nano /etc/systemd/system/znakoboom-bot.service
```

Вставь:

```ini
[Unit]
Description=Znakoboom Telegram Bot
After=network-online.target znakoboom.service
Wants=network-online.target

[Service]
Type=simple
User=znakoboom
Group=znakoboom
WorkingDirectory=/opt/znakoboom
ExecStart=/usr/bin/python3 /opt/znakoboom/bot.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Сохрани файл и включи службу:

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now znakoboom-bot
sudo systemctl status znakoboom-bot
```

Проверь журнал, если бот не отвечает:

```sh
sudo journalctl -u znakoboom-bot -n 50 --no-pager
```

Теперь открой бота в Telegram и отправь `/start`. Нажми **«Открыть игру»**.
Бот также добавит кнопку **«Открыть игру»** в меню чата. При каждом запуске
сервера/бота systemd поднимет их автоматически.

## Как обновить игру и перезапустить

После копирования новых файлов в `/opt/znakoboom` выполни:

```sh
sudo chown -R znakoboom:znakoboom /opt/znakoboom
sudo systemctl restart znakoboom
sudo systemctl restart znakoboom-bot
```

Игровой прогресс хранится в `/opt/znakoboom/data/znakoboom.sqlite3`.
**Не удаляй эту папку**, если хочешь сохранить профили. Если после обновления
папки проекта там уже лежит старая `data/nomerok.sqlite3`, Знакобум продолжит
использовать её, если новая база ещё не создана. Если обе базы есть, профили,
которых ещё нет в новой базе, перенесутся из старой автоматически. Для уже
существующих в обеих базах профилей актуальной считается запись из новой базы;
старая копия останется нетронутой. Для резервной копии останови службу и
скопируй актуальную базу:

```sh
sudo systemctl stop znakoboom
sudo cp /opt/znakoboom/data/znakoboom.sqlite3 /opt/znakoboom/data/znakoboom.backup.sqlite3
sudo systemctl start znakoboom
```

## Что такое персональная «фишка»

В меню игры открой **«Моя фишка»** и один раз выбери специализацию. Она
сохраняется для твоего Telegram-профиля:

- **Нумеролог** — выше шанс редких номеров.
- **Автодилер** — выше выплата за проданные номера.
- **Механик** — быстрее набирается опыт.
- **Архивариус** — больше мест в коллекции и сейфе.

Выбор постоянный и действует только на твой профиль; характеристики остальных
игроков он не меняет.

## Если что-то пошло не так

**Страница белая или сайт не открывается.** Проверь `sudo systemctl status
znakoboom`, журналы `sudo journalctl -u znakoboom -n 50 --no-pager` и открой
`https://game.example.ru/api/health`. Рабочий сервер ответит
`{"ok": true, "mode": "production"}`.

**Бот молчит.** Проверь `sudo systemctl status znakoboom-bot`,
`sudo journalctl -u znakoboom-bot -n 50 --no-pager` и правильность `BOT_TOKEN`
в `/opt/znakoboom/.env`.

**Кнопка открывает старый адрес.** Проверь `APP_URL` в `.env`, сохрани файл и
перезапусти обе службы. Убедись, что BotFather привязал тот же домен.

**В Telegram ошибка HTTPS.** Открой сайт в обычном браузере. Проверь, что
сертификат действителен, DNS указывает на VPS, а порты 80 и 443 доступны.

**Профиль не сохраняется.** Проверь, что папка `/opt/znakoboom/data` принадлежит
пользователю `znakoboom`: `sudo chown -R znakoboom:znakoboom /opt/znakoboom/data`.

## Проверки проекта

Из папки проекта можно прогнать тесты:

```sh
python3 -m unittest discover -s tests -v
```

Другие Python-библиотеки, Node.js/npm, компилятор и шаг сборки не нужны.
